# quick-toolbar 悬浮球交互与定位模型（v1.7→v1.11 系列决策，2026-08-30）

- 对象：`@max-null/dsh-quick-toolbar` web 悬浮球（iOS 小白点式）
- 背景：v0.1.x 时代为「标题栏聚合按钮」附属形态；独立化后以 web 悬浮球为第二载体，交互与定位模型经用户连续 5 轮反馈迭代定型。本记录为**已拍板决策档案**（防回退、防反复）。
- 参照：iOS AssistiveTouch；Material FAB 展开语义；dsh-chat-rail 画轴动画（早期参考）。

## 决策序列

### D1. 无标题通用化（v0.4）
移除「思灵工具栏」标题：插件面向任意 DSH 环境，不绑定思灵品牌。面板头部仅保留裁切与图钉。

### D2. 默认折叠 + hover 展开（拍板于 2026-08-30）
- 未钉住：默认收起为悬浮球；**鼠标移入展开、移出收起（防抖）**；钉住（pin）= 常开。
- 收起语义「快速收起」：不占屏、不打断阅读；钉住服务「反复使用」场景。
- 持久化：`ssid-toolbar-pinned`（钉住态）/ `ssid-toolbar-collapsed`（折叠态）/ `ssid-toolbar-pos`（位置）。

### D3. hover 判定 = 几何膨胀区 + 防抖（v1.7 起，定型于 v1.9）
- 历史教训①：`display:none` 切换导致 fab mouseleave → 收起循环（闪烁根因）——**不用 display 切换**。
- 历史教训②：morph 过渡中壳边界时刻移动，mouseenter/mouseleave 事件会误判。
- 定案：收起/展开全走 **document mousemove + 鼠标点 vs 壳矩形（+18px 膨胀）几何判定**；展开态离壳 220ms 收起；鼠标停住不动 = 不评估。
- 理由：状态由「最近一次鼠标位置」决定，与过渡帧/事件目标解耦；无事件抖动。

### D4. 球↔面板一体 morph（v1.8，用户方案）
- 用户明确否决「面板从球旁边缩放出现」（v1.7 画轴 scale 版）：「悬浮球原本是个圆，然后长宽展开成了一个长方形面板」。
- 定案：**一个壳 DOM**（root）承载球与面板——收起 36px 圆 ↔ 展开面板矩形，`width/height/left/top/border-radius` 五属性过渡（.28s）；球图标层独立 fixed 于球位、morph 中原地淡出。
- 收益：无「球消失、面板旁边出现」错位；双向（展开/收起）连续。

### D5. pin 徽标低调化（v1.7→v1.8）
- 36px 实底圆钮（占面板头部）→ 面板右上角 icon 徽标（26px、透明度 .75、hover 提亮、钉住 accent 高亮）。
- 折中：不得「快没了」（v1.9 用户反馈 22px/.55 过淡），保留存在感但不抢主视觉。

### D6. 自由定位、不吸附（v1.4 回退，维持）
- 边缘吸附（贴屏边）曾实现，与侧边栏/内容重叠 → 回退。保持**完全自由定位**（拖拽柄=面板头部），位置 `{x,y}` 持久化。

### D7. 球位 = 面板「屏幕外侧角」，逆放置闭环（v1.11 定案）
- 用户设计语义：「球落点取决于球在屏幕哪个象限」——面板在左上象限 → 收起球在面板左上角侧；右下象限 → 球贴面板右下角侧。
- 演进：v1.9 公式保证球位 ⊂ 面板一角（纠正对角相切）；v1.10 刚体位移（球随面板同位移）被用户纠正（拖到新象限后球不稳定）；**v1.11 最终 = 逆放置 `invertPlacement`**：由面板位反解球位，约束「从球位展开面板必须落回面板原位」（方向判定自洽），组合优先级 [右下（球=面板左上角）、左上（球=面板右下角）、右上、左下]。
- 结果：球位=锚点（localStorage），展开/收起/拖拽三态闭环，面板位置拖一次即锁定。

### D8. 展开方向自适应（v1.8 起）
- 球在右半屏 → 面板向左长；下方空间足 → 向下；四向均自适应（防出屏）。方向每次按球位重算，不记忆（D7 闭环保证稳定性）。

### D9. 面板内容随语言/适配器动态测量（v1.8 起）
- 壳展开尺寸 = 面板自然尺寸（内容测量 + 壳 border 2px），不固定宽高；i18n 语言切换、按钮增减自动适配。

## 防回退红线（用户已拍板，改动须重走决策）

1. 不做 display:none 切换的显示/隐藏
2. 不做边缘吸附回退
3. 不做「面板独立出现」的非 morph 形态
4. 球位不与面板分离（对角相切）——球必是面板一角
5. 收起/展开原点必须同一个（球位锚定）
